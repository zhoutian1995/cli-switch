# cli-switch v2.0 测试方案

> 版本：v2.0 | 更新日期：2026-04-10

## 1. 质量目标

| # | 目标 | 验证方式 |
|---|-----|---------|
| 1 | **解析正确性**：resolve 输出正确的 RuntimeSpec | 单元测试 + 集成测试 |
| 2 | **诊断正确性**：auth status / doctor 准确识别问题 | 场景测试 |
| 3 | **架构隔离**：Adapter 变更不影响 Core | contract test + 依赖检查 |
| 4 | **跨平台一致**：macOS/Linux 路径和环境解析相同 | E2E 双平台测试 |
| 5 | **输出稳定**：JSON schema 在版本内不 breaking | schema 快照测试 |

### 2.3 Adapter Contract Test（强制）

每个 Adapter 必须通过以下测试：

```python
class AdapterContractTest:
    """所有 Adapter 必须通过的统一合约测试"""

    def test_implements_all_methods(self, adapter):
        """7 个必选方法全部实现"""
        assert hasattr(adapter, 'resolve_model')
        assert hasattr(adapter, 'resolve_auth')
        assert hasattr(adapter, 'build_command')
        assert hasattr(adapter, 'doctor_checks')
        assert hasattr(adapter, 'get_capabilities')
        assert hasattr(adapter, 'get_transport_policy')
        assert hasattr(adapter, 'validate_profile')

    def test_resolve_model_returns_valid_model(self, adapter, sample_key):
        """resolve_model 返回合法 Model 对象"""
        model = adapter.resolve_model(sample_key)
        assert model.key
        assert model.model_id
        assert model.vendor
        assert model.transport

    def test_resolve_auth_returns_valid_result(self, adapter, profile, env):
        """resolve_auth 返回合法 AuthResult"""
        result = adapter.resolve_auth(profile, env, {})
        assert result.mode in ('api_key', 'login', 'oauth', 'none')
        assert result.status in ('ready', 'missing', 'expired', 'conflict', 'unsupported', 'unknown')

    def test_build_command_returns_non_empty(self, adapter, runtime_spec):
        """build_command 返回非空 CommandSpec"""
        cmd = adapter.build_command(runtime_spec)
        assert cmd.program
        assert cmd.preview()  # 预览字符串非空

    def test_doctor_checks_returns_results(self, adapter, profile):
        """doctor_checks 返回 ≥1 项"""
        checks = adapter.doctor_checks(profile)
        assert len(checks) >= 1
        for check in checks:
            assert check.name
            assert check.status in ('pass', 'fail', 'skip')

    def test_all_returns_pass_schema(self, adapter, ...):
        """所有返回值通过 JSON schema 验证"""
        ...
```

### 2.4 E2E 测试

**执行方式**：编译安装后，通过 subprocess 调用 `cli-switch` 命令。

| 场景 | 命令 | 验证 |
|-----|------|------|
| resolve JSON 输出 | `cli-switch resolve opus4.6 --json` | JSON 解析成功 + schema_version 存在 |
| auth status JSON | `cli-switch auth status --json` | status 字段合法 |
| doctor JSON | `cli-switch doctor --json` | checks 数组非空 |
| 模型切换 | `cli-switch opus4.6` | 退出码 0 + 配置文件已更新 |
| 列表 + Profile | `cli-switch list --json` | 包含 Profile 信息 |
| 错误输出 | `cli-switch resolve nonexistent --json` | error.code = MODEL_NOT_FOUND |
| 废弃命令警告 | `cli-switch validate` | 输出 deprecation warning |
| 配置目录发现 | XDG_CONFIG_HOME 变更 | 使用自定义路径 |
| 二进制缺失 | PATH 中无 claude | doctor → binary_found: fail |

## 3. 测试矩阵

### 3.1 工具 × Profile × 平台

```
工具（4）：claude-code, gemini-cli, codex-cli, opencode
Profile（3）：default, router, api
平台（2）：Linux x86_64, macOS arm64

全矩阵：4 × 3 × 2 = 24 组合
E2E 重点覆盖：4 × 1(default) × 2 = 8 组合（必测）
```

### 3.2 认证模式 × 状态

```
模式（4）：api_key, login, oauth, none
状态（6）：ready, missing, expired, conflict, unsupported, unknown

关键组合（必测）：
- api_key × ready（正常路径）
- api_key × missing（最常见错误）
- login × ready
- login × expired
- api_key × conflict（env + config 冲突）
```

### 3.3 错误场景

| 场景 | 触发条件 | 期望 |
|-----|---------|------|
| 模型不存在 | resolve nonexistent | MODEL_NOT_FOUND |
| Profile 不存在 | --profile claude-code/xxx | PROFILE_NOT_FOUND |
| 配置不可读 | chmod 000 config.yaml | CONFIG_INVALID |
| 环境变量为空 | unset ANTHROPIC_AUTH_TOKEN | auth status = missing |
| 多认证源冲突 | env + config 不同值 | auth status = conflict |
| 二进制未安装 | PATH 中无目标二进制 | doctor binary_found = fail |
| JSON 模式异常 | --json + 内部 exception | JSON 格式的错误输出 |
| schema_version 不匹配 | 旧版 config | 兼容处理或明确报错 |

## 4. Mock 策略

### 4.1 平台 Mock

```python
@pytest.fixture
def mock_platform(tmp_path, monkeypatch):
    """控制 XDG 路径和环境变量"""
    config_dir = tmp_path / "config" / "cli-switch"
    config_dir.mkdir(parents=True)
    monkeypatch.setenv("XDG_CONFIG_HOME", str(tmp_path / "config"))
    monkeypatch.setenv("XDG_DATA_HOME", str(tmp_path / "data"))
    return config_dir
```

## 5. CI Pipeline

## 6. Schema 快照测试

为保证 JSON 输出稳定，使用快照测试：

```python
def test_resolve_schema_snapshot(snapshot):
    """resolve --json 输出 schema 不意外变更"""
    result = run_resolve("opus4.6", json=True)
    # 只验证 schema 结构（key 名和类型），不验证具体值
    schema = extract_schema(result)
    assert schema == snapshot
```

快照文件存储在 `tests/snapshots/`，schema 变更需显式 `--update-snapshots`。
