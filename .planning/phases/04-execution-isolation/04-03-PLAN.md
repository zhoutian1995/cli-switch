<task type="auto">
  <name>Task 1: Implement git worktree module</name>
  <files>src/core/sandbox/worktree.ts</files>
  <read_first>src/core/git/guard.ts, src/core/sandbox/index.ts</read_first>
  <action>Create `src/core/sandbox/worktree.ts`:
  - `WorktreeConfig { branchPrefix: string; force: boolean }` with defaults: `{ branchPrefix: "wt-", force: false }`.
  - `WorktreeContext { worktreeDir: string; branch: string; cleanup: () => Promise<void> }`
  - `isGitRepo(dir: string): boolean` — check if directory is a git repo.
  - `createWorktree(baseDir: string, config?: WorktreeConfig): Promise<WorktreeContext>`
    - Verify baseDir is a git repo (error if not).
    - Create branch name: `wt-{timestamp}-{shortId}`.
    - Run `git worktree add <worktreeDir> -b <branchName>`.
    - Return context with cleanup.
  - `getWorktreeChanges(baseDir: string, worktreeDir: string): Promise<{ diff: string; commitHash?: string }>`
    - Run `git -C <worktreeDir> diff HEAD` for uncommitted changes.
    - Also run `git -C <worktreeDir> log --oneline HEAD ^HEAD` for new commits.
  - `mergeWorktree(baseDir: string, branch: string): Promise<{ success: boolean; message: string }>`
    - Run `git -C <baseDir> merge <branch> --no-ff` to merge worktree branch into current branch.
    - Handle conflicts gracefully.
  - `removeWorktree(baseDir: string, worktreeDir: string, branch: string, force?: boolean): Promise<void>`
    - Run `git -C <baseDir> worktree remove <worktreeDir>` (with `--force` if force=true).
    - Delete the branch: `git -C <baseDir> branch -D <branch>` (only if force or branch fully merged).
  - Export from barrel.</action>
  <verify>npx vitest run test/unit/worktree.test.ts</verify>
  <acceptance_criteria>
    - `createWorktree()` creates a real git worktree with a new branch.
    - `getWorktreeChanges()` returns diffs from the worktree.
    - `removeWorktree()` cleans up the worktree and branch.
    - `createWorktree()` in a non-git directory throws appropriate error.
  </acceptance_criteria>
  <done>Git worktree management module is implemented.</done>
</task>
