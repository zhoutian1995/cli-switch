  - `getPatchOnlyPromptSuffix(): string` — returns a prompt suffix instructing the agent to output unified diffs instead of modifying files: "IMPORTANT: Do NOT modify any files directly. Output your changes as unified diff format (diff --git ...). Do not run any write commands."

  </acceptance_criteria>

<task type="auto">
  <name>Task 2: Implement patch collector</name>
  <files>src/core/sandbox/patch-collector.ts</files>
  <read_first>src/core/validation/diff-validator.ts</read_first>
  <action>Create `src/core/sandbox/patch-collector.ts`:
  - Import `parseUnifiedDiff` and `validateDiffPaths` from `../validation/diff-validator.js`.
  - `PatchResult { diffs: DiffFile[]; violations: string[]; clean: boolean; rawDiffs: string }`
  - `collectPatches(agentOutput: string): PatchResult`
    - Extract diff blocks from agent output (split by "diff --git" and rejoin with headers).
    - Parse via `parseUnifiedDiff()`.
    - Validate paths via `validateDiffPaths()`.
    - Return combined result.
  - `applyPatch(diffText: string, cwd?: string, dryRun?: boolean): { success: boolean; applied: boolean; error?: string }`
    - Use `git apply --check` first if in git repo (validation only).
    - Then `git apply` to apply the diff.
    - If not in git repo, return `{ success: false, error: "Not in a git repository" }`.
    - `dryRun=true` only runs `--check`, doesn't apply.
  - Export from barrel.</action>
  <verify>npx vitest run test/unit/patch-collector.test.ts</verify>
  <acceptance_criteria>
    - `collectPatches("diff --git a/foo.ts b/foo.ts\n--- a/foo.ts\n+++ b/foo.ts\n@@ -1 +1 @@\n-old\n+new\n")` returns `{ clean: true, diffs: [...] }`.
    - `collectPatches("no diff here")` returns `{ clean: true, diffs: [], rawDiffs: "" }`.
    - `collectPatches` with protected path returns violations.
  </acceptance_criteria>
  <done>Patch collector can extract, parse, and validate diffs.</done>
</task>
