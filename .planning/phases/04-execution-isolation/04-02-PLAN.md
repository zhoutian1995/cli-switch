  - `TempCopyContext { srcDir: string; copyDir: string; cleanup: () => Promise<void> }`
  - `createTempCopy(srcDir: string, config?: TempCopyConfig): Promise<TempCopyContext>`

    - Return context with cleanup function.
  - `computeCopyDiff(srcDir: string, copyDir: string): Promise<string>`
    - Use `git diff --no-index srcDir copyDir` to compute diff (works even without git tracking).
    - If git not available, fall back to a simple file-by-file comparison that generates unified diff format.
