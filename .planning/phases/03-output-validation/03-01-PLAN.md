  <files>src/core/validation/output-schemas.ts</files>
  <read_first>src/types/capability.ts, docs/specs/runtime-spec.md</read_first>
  <action>Create `src/core/validation/output-schemas.ts` with Zod schemas for each capability's output:
  - Base schema: `{ status: z.enum(["success","failed"]), summary: z.string() }`
  - write_code: base + `files_changed: z.array(z.string())`, `diff: z.string()`
  - write_tests: base + `test_files_created: z.array(z.string())`
  - run_tests: base + `test_result: z.object({ status: z.enum(["pass","fail"]), output: z.string() })`
  - review_code: base + `review_report: z.object({ verdict: z.enum(["pass","reject"]), comments: z.array(z.string()) })`
  - fix_error: base + `files_changed: z.array(z.string())`, `diff: z.string()`
  - refactor: base + `files_changed: z.array(z.string())`, `diff: z.string()`, `test_validation: z.object({ status: z.enum(["pass","fail"]), output: z.string().optional() })`
  - analyze: base + `analysis_report: z.object({ root_cause: z.string(), suggestion: z.string() })`
  - explain: base + `explanation_text: z.string()`
  - Export a `getOutputSchema(capability: CapabilityId)` function that returns the appropriate Zod schema.
  - Use `z.object({...}).passthrough()` to allow extra fields without stripping.
  - Also create `src/core/validation/index.ts` barrel export.</action>
  <verify>node -e "const m = require('./src/core/validation/output-schemas.ts'); console.log('OK')" 2>&1 || npx vitest run test/unit/validation-schemas.test.ts</verify>
  <acceptance_criteria>

    - `getOutputSchema('write_code')` rejects objects missing `files_changed`.
    - Extra fields like `confidence` pass validation without error.
  </acceptance_criteria>

    - Try JSON.parse first. If output is valid JSON, validate against schema.
    - If not JSON, return `{ valid: false, errors: ["Output is not valid JSON"] }` — we don't attempt text extraction in this plan (that's auto-repair in 03-02).

  - Export from barrel.
  - Add `ValidatedOutput` type to `src/types/strategy.ts` as `type ValidatedOutput = { status: "success" | "failed"; summary: string; [key: string]: unknown }` and add optional `validatedOutput?: ValidatedOutput` to `StepHistory` interface.</action>

  <acceptance_criteria>
